# Banking Console Application

**Kiran Academy – Task 03**  
A beginner-friendly console banking application written in Python.

## Features
- Starts with an opening balance of ₹10,000
- Check current balance
- Deposit money greater than zero
- Withdraw money only when the balance is sufficient
- Handles invalid menu choices and non-numeric amounts
- Repeats the menu until the user chooses Exit

## Requirements
- Python 3
- No external libraries required

## How to Run
1. Open a terminal in this folder.
2. Run:

   ```bash
   python banking_application.py
   ```

   On some systems, use `python3 banking_application.py`.
